=== ORWO Studios ===
Requires at least: 6.6
Tested up to: 6.8
Requires PHP: 8.1
License: GPL-2.0-or-later

Editable WordPress block theme for ORWO Studios, the film and TV studio in Baton Rouge, Louisiana.

== Installation ==
1. Appearance > Themes > Add New > Upload Theme: upload orwo-studio.zip and activate it.
2. Appearance > ORWO Studios Setup > Complete ORWO Studios setup.
   This imports the images into the Media Library, then creates the original pages, blog articles,
   categories, menu, header and footer at the original addresses. Existing content is never overwritten.
3. Settings > General: check the "ORWO Studios form recipient" (default hello@orwo.studio).
4. Send one test message through the contact form and confirm it arrives.
